# Diary GUI

基于 Web 的日记阅读器，使用 FastAPI 后端 + 纯 HTML/CSS/JS 前端。

## 🚀 启动方式

```bash
python gui.py
```

一键启动后端服务并自动打开浏览器。

---

## 🛠️ 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端 | FastAPI | 轻量 Python Web 框架 |
| 前端 | HTML + CSS + JS | 无框架，简单直接 |
| Markdown 渲染 | marked.js | 轻量 Markdown 解析库 |
| 缓存策略 | 启动时全量加载 | 所有日记加载到内存，响应极快 |

---

## 📋 功能提案

### 第一阶段：核心功能（MVP）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 📅 日记列表 | 按时间倒序显示所有日记，显示日期和标题 | ⭐⭐⭐⭐⭐ |

| 🔍 快速搜索 | 按关键词搜索日记内容 | ⭐⭐⭐⭐ |
| ⏳ 待评论标记 | 显示哪些日记还没有生成 AI 评论 | ⭐⭐⭐⭐ |

| 功能 | 描述 | 优先级 |

| 📆 日历视图 | 用日历形式浏览日记 | ⭐⭐⭐ |
| 🎨 主题切换 | 亮色/暗色模式 | ⭐⭐ |

### 第三阶段：高级功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| ☁️ 词云图 | 可视化高频词汇 | ⭐⭐ |
| 📤 导出功能 | 导出为 PDF / HTML | ⭐⭐ |
| 🔗 关联日记 | 显示生成评论时使用了哪些历史日记 | ⭐⭐ |
| 📁 文件监控 | 自动检测新日记，实时刷新列表 | ⭐ |

## 🔌 API 设计

| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/diaries` | GET | 获取所有日记的元信息（日期、标题、是否有评论） |
| `/api/diary/{date}` | GET | 获取指定日期的日记详情（内容、评论、usage） |
| `/api/search?q=xxx` | GET | 搜索日记内容 |
| `/api/stats` | GET | 获取统计信息 |

## 📝 开发笔记

- 命令行的 `diary.py` 和 `comment.py` 保持不变，GUI 只用于阅读
- 所有日记在服务启动时加载到内存缓存，保证响应速度
- 前端不使用任何框架，保持简单
